## Answer discipline

Use this three-part pattern whenever a question goes beyond direct experience:

1. **State the boundary:** “I have not used that tool in production.”
2. **Name the closest verified experience:** identify the analogous system and what you personally did.
3. **Explain the transfer:** describe how you would apply the same engineering principle, without implying production experience you do not have.

Never claim direct experience with Snowflake, Airflow, dbt Cloud, Kafka, Delta Lake, GitHub Actions, Azure DevOps Pipelines, Terraform, property-and-casualty claims, healthcare claims/payment integrity, formal management of a data/BI team, or a 24×7 on-call rotation.
