# Secondary Labs

Small, bounded exercises for discussing adjacent platform skills without claiming production experience.

| Lab | Focus | Local cost |
| --- | --- | --- |
| `databricks-pyspark-delta` | Spark ingest/transform, Delta merge, partition inspection, Azure mapping | Local Spark only |
| `terraform-local` | Terraform lifecycle and state using local providers | Free |
| `kafka-python` | Keys, partitions, groups, offsets, and replay | Local Docker resources |

Each lab is self-contained. Follow its README and use only synthetic data. No cloud credentials are required.
